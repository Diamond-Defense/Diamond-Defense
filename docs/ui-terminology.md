# UI terminology

Use these terms in navigation, actions, instructions, accessible labels, and feedback.

- **Coach Board**, **Play**, **Training**, **Design**, **Organization**, and **Guide** are workspace names.
- A **Board** is a private authored diagram or animation. Use **Save Board**, **Export Board**, and **Import Board**.
- A **Situation** is a library exercise. Use **Create Situation**, **Review Situation Changes**, and **Publish Situation** for the corresponding steps. Proposals are submitted for review rather than described as published.
- **Situation Library** contains situations; **Board & Situation Library** contains both. Use **Team Situation Library** for the team-specific library. Global Library, Organization Library, and Regional Library remain scope names.
- **Player preview** / **Preview as player** means trying a draft or revision from the player's perspective.
- An **attempt** is one recorded try at a situation. Training counts attempts; a situation may have many attempts. Retain baseball terms such as double play and force play.
- **Start Situation** begins a player attempt. **Play**, **Pause**, and **Replay** control Coach Board playback. **Watch Solution** and **Replay Solution** refer to solution playback. **Reset** restarts the player situation, and **Reset coaching preferences** restores display defaults.
- **Retry** repeats a failed loading operation. **Log in**, **Log out**, and **Log out everywhere** are account actions.
- **Difficulty** filters use **All difficulties**. Counts and empty states name the actual content: Boards, situations, or both.

Internal identifiers, API routes, database names, stored records, and historical audit data do not need to match UI wording. Do not rename them for a terminology-only change.
